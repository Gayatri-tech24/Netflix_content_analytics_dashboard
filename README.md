# Netflix Content Analytics Dashboard

An interactive data visualization dashboard designed to analyze and explore the Netflix content catalog, providing insights into content distribution across media types, genres, release years, ratings, and producing countries.

## 📊 Features & Key Metrics

* **Key Performance Indicators (KPIs):**
  * **Total Titles:** 8,807
  * **Movies:** 6,131
  * **TV Shows:** 2,676
* **Visualizations:**
  * **Content Type Breakdown:** Donut chart illustrating the ratio of Movies vs. TV Shows.
  * **Genre Distribution (`listed_in`):** Bar chart tracking top genres (e.g., Dramas, Comedies, Children & Family).
  * **Geographic Distribution (`country`):** Horizontal bar chart mapping production volume across leading countries (United States, Japan, France, etc.).
  * **Rating Analysis (`rating`):** Line trend detailing content breakdown across maturity ratings.
  * **Release Year Trends (`release_year`):** Historical trend line showing volume growth over time.
* **Interactive Slicers:** Dynamic filtering capabilities by content type (`Movie` / `TV Show`), producing country, and maturity/duration ratings.

---

## 🛠️ Tech Stack

* **Tool / Platform:** Excel Pivot Dashboard / Power BI / Tableau
* **Data Source:** Netflix Movies and TV Shows Dataset
* **Data Processing:** Power Query / Excel Pivot Tables
